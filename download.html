Install steps

First-run guidance from the app's own documentation.

  1. Download TeleVault-windows-x64.exe and run it.
  2. Windows may show “Windows protected your PC”. Click More info, then Run anyway to continue.
  3. Complete the first-run setup with your own Telegram API credentials.

SmartScreen warnings are expected for a beta distributed as a direct download. These steps follow the app's release handoff.

  1. Download TeleVault-macos-arm64.dmg from the release page and open it with Finder.
  2. Drag TeleVault.app into /Applications, then eject the DMG.
  3. Launch TeleVault from Applications. On first launch macOS warns about the app's origin (“TeleVault” Not Opened). Click Done, not Move to Trash.
  4. Open System Settings → Privacy & Security, scroll to the Security section, and click Open Anyway next to the TeleVault entry. Confirm with your Mac password when asked. On macOS 14 and earlier you can instead Control-click TeleVault.app in Applications and choose Open, then Open in the dialog.
  5. macOS remembers this exception, so later launches open normally.

This beta is distributed directly from the GitHub release, so Gatekeeper warns on first launch. If the Intel build offers only Move to Trash on macOS 15, use the Apple Silicon build on Apple hardware. Full steps are in the app's troubleshooting guide.

  1. Choose the AppImage, .deb or .rpm build above.
  2. For the AppImage, make it executable and run it: chmod +x TeleVault-linux-x64.AppImage then ./TeleVault-linux-x64.AppImage. AppImages need FUSE; if your desktop does not provide it, install libfuse2 or unpack the file with --appimage-extract.
  3. For Debian / Ubuntu, install the package with sudo apt install ./TeleVault-linux-x64.deb. For Fedora / RHEL, use sudo dnf install ./TeleVault-linux-x64.rpm.
  4. TeleVault stores the AES encryption key and the hidden-folder PIN in the OS credential store through keytar. On Linux that means libsecret plus a running secret service (GNOME Keyring, KDE Wallet, or equivalent) in the desktop session.
Libsecret packages
Distributor Install command
Debian / Ubuntu sudo apt install libsecret-1-0
Fedora / RHEL sudo dnf install libsecret
Arch / Manjaro sudo pacman -S libsecret

The .deb declares libsecret-1-0 as a dependency and installs it automatically. The AppImage cannot declare dependencies, so install libsecret yourself before first run.

Verify your download

Every release publishes SHA256SUMS.txt. A SHA-256 hash is a fingerprint for a file: compare the hash of your download with the published value before you install.

  • Windows (PowerShell) Get-FileHash .\TeleVault-windows-x64.exe -Algorithm SHA256
  • macOS shasum -a 256 TeleVault-macos-arm64.dmg
  • Linux sha256sum TeleVault-linux-x64.AppImage

Open SHA256SUMS.txt

What the app contacts

TeleVault connects to Telegram for login, channels and file sync. It also checks GitHub for updates after startup: the update client requests release metadata and a small channel file. That request carries a random ID generated once on your device and stored at <userData>/.updaterId as x-user-staging-id. No auth token, Telegram data, file names or file contents are attached. A failed check is silent and the app keeps working; an installer is downloaded only after you choose to download it. There is no analytics or crash reporting.

Source: FACTS_FOR_WEBSITE.md, §5a.

Known issues in this beta

From the app's release handoff. Please read these before you rely on the app.

Known issues
Area Issue Detail
Encryption Key loss is permanent Losing the OS-keychain key makes encrypted files permanently unreadable. This beta has no recovery-key export/import; a guard blocks silent key replacement when encrypted rows exist, and the toggle is disabled when no secure key store is available.
Delete “Remove from TeleVault” is local-only It removes the file from TeleVault but does not delete its messages in Telegram. The data stays in your Telegram until you delete the messages there.
Delete “Delete permanently” is irreversible It deletes the file's recorded Telegram messages and its local records. Cached thumbnails, old sync snapshots and archived version messages are not removed.
Sync Last-writer-wins full replace Conflicts are not resolved per item: the most recently pushed device wins entirely and can overwrite newer local metadata. A local DB backup is taken before each full replace, but conflict resolution is still needed.
Trash 30-day purge is local-only Expired trash rows lose their local references at startup and daily. The purge is local only, so the messages stay in your Telegram account until you delete them there.
First launch Operating-system warnings are expected Windows SmartScreen and macOS Gatekeeper warn when you first open this direct-download beta. Use the install steps above to continue.
Features Incomplete File version history and tags are not available yet; share links point to private Telegram channels and are not usable by non-users.
