Privacy

What TeleVault stores, encrypts, deletes and sends over the network.

Plain-language drafts, not legal advice.

Files and metadata

TeleVault is a desktop client for the Telegram account you already use. File contents are encrypted on your device with AES-256-GCM when encryption is on, and decryption happens locally when you download. The key is 32 random bytes held in your operating system's keychain; it is generated on your device and is not uploaded.

File names, paths, MIME types, sizes, folder names and cached thumbnails are not encrypted. They are written into Telegram message captions and into a local SQLite database in clear text. The Telegram session is also stored locally. TeleVault runs no server that stores your files, and there is no account with us.

Your encryption key

If you lose the key, files encrypted with it cannot be read. There is no key escrow, and this beta has no recovery-key export or import. The app will not silently replace a missing key when encrypted rows exist, and encryption is disabled if no secure key store is available. Back up your operating system keychain.

Deleting and expiry

“Delete permanently” is irreversible: it deletes the file's recorded Telegram messages and its local records. Cached thumbnails, old sync snapshots and archived version messages are not removed.

Trash entries expire after 30 days. That sweep is local only — it removes local references, so the messages stay in your Telegram account until you delete them there.

Sync

Sync is last-writer-wins: a conflict is not resolved per item, and the most recently pushed device can overwrite newer local metadata. TeleVault makes a local backup before applying a pull.

Network requests

TeleVault connects to Telegram for login, channels and file sync. After startup it also checks GitHub for updates. That request sends a random ID generated once on your device, stored at <userData>/.updaterId and sent as x-user-staging-id. No auth token, Telegram data, file names or file contents are attached. A failed check is silent, and an installer is downloaded only after you choose to download it.

Links open in your operating system's browser only when you click them. There is no analytics, crash reporting, license server or payment endpoint.
